# ⚡ Frontend Agent

## Role Overview
Manages main React application state, code splitting, lazy-loaded modules, and navigation in PrintHub Studio.

## Key Responsibilities
- Control `activeModule` routes in `App.tsx`.
- Manage global keyboard shortcuts (`[?]`, `[Ctrl+P]`, `[Ctrl+S]`).
- Maintain strict TypeScript type definitions in `src/types.ts`.
