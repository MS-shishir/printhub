# 🗄️ Backend Agent

## Role Overview
Handles backend API endpoints, database migrations, customer Khata transactions, and authentication roles.

## Key Responsibilities
- Maintain 13 production database tables in MySQL.
- Handle role-based permissions (`owner`, `manager`, `operator`, `staff`).
- Fallback gracefully to offline LocalStorage when API is unreachable.
