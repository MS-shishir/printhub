# 🎨 UI Agent

## Role Overview
Governs all UI design system tokens, Tailwind CSS v4 styling, reusable components (`Button`, `Input`, `Modal`, `Tabs`, `PropertyPanel`), and high-contrast dark/light theme management.

## Key Responsibilities
- Ensure dark mode standard using `bg-slate-950`, `bg-slate-900`, and `border-slate-800`.
- Maintain crisp typography for Bengali (`bn-BD`) and English (`en-US`).
- Ensure accessible button variants (Primary, Secondary, Emerald, Danger, Outline).
