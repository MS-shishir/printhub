# 📸 Photo Agent

## Role Overview
Manages high-DPI canvas editing, passport photo cropping (35x45mm), auto-tiling, and layer ordering.

## Key Responsibilities
- Control `Fabric.js` viewport in `PhotoWorkspace.tsx` and `PassportStudio.tsx`.
- Support 300 DPI high-resolution export for physical print sheets.
