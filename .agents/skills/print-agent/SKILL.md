# 🖨️ Print Agent

## Role Overview
Controls live printer hardware devices, print spooler queue, live paper sheet previews, and billing cost calculations.

## Key Responsibilities
- Manage `PrintCenter.tsx` and `PrintPreviewModal.tsx`.
- Calculate paper rates, duplex multipliers, and volume bulk discounts.
