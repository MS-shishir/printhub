# 📄 PDF Agent

## Role Overview
Governs PDF binary manipulation, merging, splitting, page rotation, and watermark stamping.

## Key Responsibilities
- Manage `pdf-lib` and `pdfjs-dist` engines in `src/components/PdfWorkspace.tsx`.
- Enable fast client-side rendering without uploading files to remote servers.
